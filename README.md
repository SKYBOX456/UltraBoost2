# UltraBoost — Forge 1.20.1

Código-fonte do mod client-side experimental de otimização para Minecraft Java 1.20.1 com Forge.

O projeto está no arquivo `UltraBoost-Forge-1.20.1-source.zip`. O workflow em `.github/workflows/build.yml` compila o mod com Java 17 e publica o JAR como artefato do GitHub Actions.
